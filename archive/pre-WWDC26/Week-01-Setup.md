# Archived Week 1 — Setup

> Original window: May 19–25, 2026. This checklist is retained only as a
> historical snapshot. Do not use it as the active setup guide.

The original week attempted to configure the entire eight-month toolchain
before validating the learning path. Its target was approximately 27 hours and
included:

- Python 3.12+, `uv`, `google-genai`, the Anthropic SDK, and `.env` handling.
- Google AI Studio and Vertex AI authentication through Application Default
  Credentials.
- A personal GCP project, APIs, billing alert, `gcloud`, Docker Desktop, and
  Terraform.
- Hashnode, GitHub portfolio placeholders, an AWS account, and a Notion/Linear
  tracker.
- Xcode 16, an iOS 18 simulator, MLX, and a local Gemma 3 experiment.

## Original daily sequence

1. Tuesday: Python skeleton, Gemini/Anthropic SDKs, and environment variables.
2. Wednesday: Hashnode account and kickoff post.
3. Thursday: GitHub placeholders and Docker.
4. Friday: GCP, Vertex AI, `gcloud`, and ADC.
5. Saturday: Xcode, MLX, Gemma, Terraform, and blog publication.
6. Sunday: tracker, AWS, and three hello-world checks.
7. Monday: buffer and review.

## Why this setup week is not reused

- Tool installation was treated as progress even when it did not demonstrate a
  competency.
- Several choices are now stale: Gemini 2.5 defaults, ADK 1.x assumptions,
  Vertex Agent Engine naming, Xcode 16, and pre-WWDC26 Apple APIs.
- It provisioned optional systems such as AWS and Terraform before they were
  needed.
- It did not begin with a diagnostic of Python, backend, DSA, system design, or
  Apple hardware constraints.

The replacement orientation is in
[Sprint 00](../../sprints/Sprint-00-Orientation.md).
